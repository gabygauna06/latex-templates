# Faculty Work Template

Professional bilingual LaTeX template for formal faculty coursework and academic submissions.

## Structure

- `assets/`
- `lang/`
- `src/`
- `out/`
- `main-es.tex`
- `main-en.tex`

## Build Output

Compiled files must be written to `out/latex/` and remain ignored by Git.

## Notes

This template follows the shared structure used across the template collection.
The file `assets/faculty-logo.png` contains the institutional UNDEF/IUA logo used by the cover and should be preserved or intentionally replaced.

# Faculty Work Template

Plantilla bilingüe en LaTeX para trabajos formales de facultad y entregas académicas.

## Estructura

- `assets/`
- `lang/`
- `src/`
- `out/`
- `main-es.tex`
- `main-en.tex`

## Salida de Compilación

Los archivos compilados deben escribirse en `out/latex/` y permanecer ignorados por Git.

## Notas

Esta plantilla sigue la estructura compartida utilizada en la colección de plantillas.
El archivo `assets/faculty-logo.png` contiene el logotipo institucional UNDEF/IUA utilizado en la portada y debe conservarse o reemplazarse de manera intencional.

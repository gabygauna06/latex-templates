# Templates

This directory contains self-contained LaTeX templates. Each template must compile on its own.

## Expected layout (per template)
- `main-es.tex`, `main-en.tex` (entrypoints)
- `src/` (core sources: template/metadata/references)
- `lang/` (bilingual bodies)
- `assets/` (logo + figures)
- `README.md` + `README.es.md` in every folder

## Available templates
- `faculty-work-template/` — Faculty assignment template (cover + submission page, ES/EN bodies)
